# 🌌 ZENITH | High-Fidelity Anime Archival Nexus

Zenith is a premium, high-density anime management platform and discovery engine. Built with a "Command Center" aesthetic, it utilizes neural-network analysis to provide hyper-personalized recommendations while maintaining a robust, hardware-accelerated archival interface.

![Zenith Preview](https://picsum.photos/seed/zenith-preview/1200/600)

## 🔭 Core Archival Sectors

### 🎮 **Discovery Command**
Navigate the global anime database with the Zenith Discovery Engine. Utilizing Pure AniList GraphQL Telemetry, users can filter through thousands of records via the Chromatic Genre Matrix and real-time airing schedules.

### 🧠 **Neural AI Recommendations**
Zenith AI analyzes your consumption history and emotional resonance profile to predict your next favorite series. Powered by **Google Genkit & Gemini 2.5**, the recommendation engine provides deep insights into why a series aligns with your profile.

### 📼 **Archival Watchlist**
A high-fidelity management system for your personal library. Track progress, status, and historical data with zero-flicker, hardware-accelerated UI components.

### 📡 **Broadcast Center**
Receive real-time alerts for new episode releases and global anime news. The Zenith Persistence Protocol ensures you never miss a beat in the airing cycle.

## 🛠 Tech Stack (Zenith Pure Protocol)

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Intelligence**: [Google Genkit](https://firebase.google.com/docs/genkit) + Gemini 2.5 Flash
- **Database & Auth**: [Firebase Firestore](https://firebase.google.com/docs/firestore) & [Firebase Authentication](https://firebase.google.com/docs/auth)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + [ShadCN UI](https://ui.shadcn.com/)
- **Telemetry**: [AniList GraphQL API](https://anilist.gitbook.io/anilist-apiv2-docs/)
- **Visuals**: [Lucide React Icons](https://lucide.dev/) & [Recharts](https://recharts.org/)

## 🚀 Deployment & Archival Setup

### 1. Repository Initialization
Clone the nexus and install the required dependencies:
```bash
git clone https://github.com/your-username/zenith-anime-archive.git
cd zenith-anime-archive
npm install
```

### 2. Environment Configuration
Create a `.env` file in the root directory and provide your Google AI credentials:
```env
GEMINI_API_KEY=your_api_key_here
```

### 3. Development Mode
Ignite the Zenith core in development mode:
```bash
npm run dev
```

### 4. Hosting via Firebase App Hosting
The project is pre-configured for **Firebase App Hosting**. Connect your GitHub repository to the Firebase Console to trigger automatic global deployments on every push.
